Source audit log

Two automated checks run against this data: a staleness check on every push (are entries marked "current" actually being re-reviewed?), and a monthly deep check that fetches each entry's live source page and flags anything that looks inconsistent with what's recorded. Flags here are a prompt to re-check a source directly — never a conclusion. Nothing is edited automatically; see CONTRIBUTING.md.
